## ad4114_sample_manager 模块

一块板子 16 路 AD5560，用 2 片 AD4114。总共 8 个板子，16 片 AD4114 使用同一个 SPI。

i_start 后 16 片 AD4114 依次初始化配置。

初始化配置流程：复位（等 500us），回读 ID （应为 0x30D），配置各寄存器（滤波、采样模式）。

单片 AD4114 配置：8 通道差分采样、20ms 滤波，不开增强型、连续采样，采一圈 160ms。

所有初始化配置完成后进入 ST_POLL 状态，读取 ADC 采样结果，先拉低 cs，等一段时间后查询 miso 是否拉低，代表是否有数据，有数据则读，没数据则切换下一个。

每次有数据则 sample_valid = 1。skip_cnt 可以选择几个点输出一次，用于切档稳定。

模块输出：数据、以及数据对应的通道号、哪一片 AD4114，用以对应是哪个 AD5560 的数据。

## measurement manager 模块

根据数据的 id 判断是哪个 ad5560 的数据，存到相应地址的 ram 中。

负责 V/I 切换，每次某通道采样一个数据后就切换，等下次再采都是 160ms 了，数据应稳定了。

默认切换的很快，相对于 160ms 来说肯定切完了。

保存 vi_state[128] 根据这个区分数据是电流还是电压，存入不同的地方，每次切换后更改对应 bit 状态。

关键是切换的时候要切 gain （0x1）和 measout 输出（0x2），不同电压、电流挡位要选择不同的 gain。

电压 gain 根据 FIN DAC 决定，电流 gain 根据电流挡位决定。

初版调试实现：仅实现存储，暂不实现自动切换 V\I。上位机手动切换先测。
